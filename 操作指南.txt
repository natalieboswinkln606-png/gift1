  ── 圣诞场景 ──

  粒子形态：
  ┌──────────────┬─────────────────────────────────────────┐
  │  1           │  圣诞树形态（默认）                     │
  │  2           │  散开形态（银河状散布）                  │
  │  5           │  爱心形态                               │
  └──────────────┴─────────────────────────────────────────┘

  照片操作：
  ┌──────────────┬─────────────────────────────────────────┐
  │  3           │  打开第一张照片                         │
  │  ← →         │  切换上一张/下一张照片                  │
  │  Esc         │  关闭当前照片                           │
  │  鼠标点击    │  点击照片打开，点击空白处关闭           │
  └──────────────┴─────────────────────────────────────────┘

  雪花绘画：
  ┌──────────────┬─────────────────────────────────────────┐
  │  P           │  进入绘画模式                           │
  │  Esc         │  退出绘画模式                           │
  │  + / =       │  增大画笔（最大 80）                    │
  │  - / _       │  缩小画笔（最小 10）                    │
  │  鼠标左键拖动│  擦除积雪                               │
  └──────────────┴─────────────────────────────────────────┘

  3D 视角：
  ┌──────────────┬─────────────────────────────────────────┐
  │  左键拖拽    │  旋转                                   │
  │  右键拖拽    │  平移                                   │
  │  滚轮        │  缩放                                   │
  └──────────────┴─────────────────────────────────────────┘

  音乐播放器（右下角）：
  ┌──────────────┬─────────────────────────────────────────┐
  │  点击音乐图标│  展开播放器                             │
  │  ▶ / ⏸      │  播放 / 暂停                            │
  │  ⏮ / ⏭      │  上一曲 / 下一曲                        │
  │  进度条点击  │  跳转到指定位置                         │
  │  音量滑块    │  拖动调节音量                           │
  │  列表按钮    │  展开播放列表，点击曲目切换             │
  │  Add Music   │  上传本地音乐文件                       │
  │  ∨ 按钮      │  收起播放器                             │
  └──────────────┴─────────────────────────────────────────┘
