================================================================================
                    新年祝福贺卡 — 操作指南
================================================================================

  本指南帮助你快速了解贺卡的所有功能和操作方式。
  贺卡通过浏览器访问，支持电脑和手机。

  访问地址：/gift/你的专属ID
  例如：https://你的域名/gift/yilong


================================================================================
  一、整体流程概览
================================================================================

  贺卡共有 5 个场景，按以下顺序体验：

  加载画面 → 礼盒场景 → 欢迎场景 → 场景选择器 → 圣诞场景 或 星河场景

  每个场景都有独特的 3D 视觉效果和交互方式。


================================================================================
  二、加载画面
================================================================================

  打开链接后，首先看到黑色背景上闪烁的白色星点和"正在准备..."的提示文字，
  下方有一个进度条显示加载进度。

  操作：无需任何操作，等待加载完成即可自动进入下一个场景。


================================================================================
  三、礼盒场景
================================================================================

  画面中央有一个 3D 礼盒，周围有灯笼和光效装饰。
  底部有金色提示文字"轻启礼盒 · 纳福迎祥"。

  操作方式：
  ┌─────────────────────────────────────────────────────────┐
  │  电脑：鼠标点击礼盒                                      │
  │  手机：手指点击礼盒                                      │
  └─────────────────────────────────────────────────────────┘

  点击礼盒后，礼盒会播放开启动画（盒盖打开、相机推进），
  动画结束后自动进入欢迎场景。


================================================================================
  四、欢迎场景
================================================================================

  画面中央显示个性化祝福文字：
    "祝 [你的名字]"
    "2026"
    "新年快乐"

  背景有多个浮动的图标精灵和烟花效果。

  ── 图标互动 ──

  操作方式：
  ┌─────────────────────────────────────────────────────────┐
  │  电脑：将鼠标移到图标上方                                  │
  │  手机：手指在屏幕上滑动触碰图标                             │
  └─────────────────────────────────────────────────────────┘

  当鼠标/手指靠近某个图标时，会弹出一个金色边框的祝福气泡，
  显示一条随机祝福语（打字机效果逐字显示）。
  移开后气泡消失。

  ── 隐藏彩蛋 ──

  画面中有一个几乎透明的圆形隐藏按钮，位置随机（避开画面中央区域）。
  它非常隐蔽，只有微弱的半透明效果。

  操作方式：
  ┌─────────────────────────────────────────────────────────┐
  │  仔细观察画面边缘区域，寻找一个微弱的圆形光点              │
  │  点击它会弹出特别鸣谢气泡，3 秒后自动消失                  │
  └─────────────────────────────────────────────────────────┘

  ── 进入下一场景 ──

  操作方式（任选其一）：
  ┌─────────────────────────────────────────────────────────┐
  │  方式 1：向下滚动鼠标滚轮                                 │
  │  方式 2：按键盘 ↓（向下箭头键）                            │
  │  方式 3：手机上向上滑动屏幕（类似翻页手势）                 │
  │  方式 4：点击右下角的"下一场景"按钮                        │
  └─────────────────────────────────────────────────────────┘

  触发后，图标会播放退场动画，烟花停止，随后进入场景选择器。


================================================================================
  五、场景选择器
================================================================================

  画面分为左右两个面板：

    左侧："圣诞"  —— 温暖归途 · 灯火阑珊
    右侧："星河"  —— 终极浪漫 · 永恒答案

  每个面板都有精美的背景图片。

  操作方式：
  ┌─────────────────────────────────────────────────────────┐
  │  电脑：鼠标悬停在某个面板上，该面板会放大、另一个变暗       │
  │        点击面板进入对应场景                                │
  │  手机：直接点击想要进入的面板                              │
  └─────────────────────────────────────────────────────────┘


================================================================================
  六、圣诞场景（重点场景，功能最丰富）
================================================================================

  这是一个 3D 粒子场景，包含圣诞树、银河、爱心等多种粒子形态，
  配合照片展示、雪花绘画、背景音乐等丰富功能。

  ── 6.1 粒子形态切换 ──

  场景中有约 4.5 万个粒子，可以在不同形态之间切换：

  键盘快捷键：
  ┌──────────┬──────────────────────────────────────────────┐
  │  按键    │  效果                                        │
  ├──────────┼──────────────────────────────────────────────┤
  │  1       │  圣诞树形态（默认）                           │
  │  2       │  散开形态（银河状散布）                        │
  │  5       │  爱心形态                                     │
  └──────────┴──────────────────────────────────────────────┘

  粒子会以流畅的动画从一种形态过渡到另一种。

  ── 6.2 照片查看 ──

  如果你的贺卡配置了照片，照片会以 3D 相框的形式悬浮在场景中。

  操作方式：
  ┌─────────────────────────────────────────────────────────┐
  │  点击照片：照片放大到屏幕中央，粒子自动切换到散开形态      │
  │  再次点击画面任意位置：关闭照片，粒子恢复之前的形态        │
  │                                                         │
  │  键盘 ←/→：在多张照片之间切换（自动切换到散开形态）       │
  │  键盘 3：打开第一张照片                                  │
  │  键盘 Esc：关闭当前照片                                  │
  └─────────────────────────────────────────────────────────┘

  ── 6.3 3D 视角控制 ──

  操作方式：
  ┌─────────────────────────────────────────────────────────┐
  │  电脑：                                                  │
  │    鼠标左键拖拽 —— 旋转视角                              │
  │    鼠标右键拖拽 —— 平移视角                              │
  │    鼠标滚轮 —— 缩放                                     │
  │                                                         │
  │  手机：                                                  │
  │    单指拖拽 —— 旋转视角                                  │
  │    双指捏合 —— 缩放                                     │
  │    双指拖拽 —— 平移视角                                  │
  └─────────────────────────────────────────────────────────┘

  ── 6.4 雪花绘画模式 ──

  这是一个特别的互动功能：在 3D 场景上覆盖一层白色"积雪"，
  你可以用手指/鼠标在上面画画，擦除积雪露出下方的 3D 场景。

  进入绘画模式：
  ┌─────────────────────────────────────────────────────────┐
  │  按键盘 P 键                                             │
  └─────────────────────────────────────────────────────────┘

  进入后会播放一段雪花飘落动画（约 0.8 秒），然后屏幕被白色积雪覆盖。

  绘画操作：
  ┌─────────────────────────────────────────────────────────┐
  │  电脑：按住鼠标左键拖动来擦除积雪                         │
  │  手机：手指在屏幕上滑动来擦除积雪                         │
  └─────────────────────────────────────────────────────────┘

  调整画笔大小：
  ┌──────────┬──────────────────────────────────────────────┐
  │  按键    │  效果                                        │
  ├──────────┼──────────────────────────────────────────────┤
  │  + 或 =  │  增大画笔（每次 +10，最大 80）               │
  │  - 或 _  │  缩小画笔（每次 -10，最小 10）               │
  └──────────┴──────────────────────────────────────────────┘

  退出绘画模式（任选其一）：
  ┌─────────────────────────────────────────────────────────┐
  │  方式 1：按 Esc 键                                       │
  │  方式 2：点击右上角的 ✕ 按钮                              │
  │  方式 3：擦除超过 50% 的积雪面积，自动触发融化动画退出     │
  │  方式 4：30 秒内不操作，自动退出                          │
  └─────────────────────────────────────────────────────────┘

  融化动画：积雪会向下滑动并淡出，露出完整的 3D 场景。

  ── 6.5 背景音乐 ──

  场景加载完成后会自动准备背景音乐（默认曲目 Harbor）。

  音乐播放器位于屏幕右下角，默认折叠为一个小圆形图标。

  操作方式：
  ┌─────────────────────────────────────────────────────────┐
  │  点击右下角音乐图标 —— 展开播放器                        │
  │                                                         │
  │  展开后可用功能：                                        │
  │    播放/暂停按钮（中央橙色圆形按钮）                      │
  │    上一曲 / 下一曲（播放按钮两侧）                        │
  │    进度条 —— 点击可跳转到指定位置                         │
  │    音量滑块 —— 拖动调节音量                              │
  │    播放列表按钮 —— 查看和切换曲目（多首歌时显示）          │
  │    "Add Music"按钮 —— 上传本地音乐文件                   │
  │    收起按钮（右上角 ∨）—— 折叠播放器                     │
  └─────────────────────────────────────────────────────────┘

  ── 6.6 圣诞场景快捷键汇总 ──

  ┌──────────┬──────────────────────────────────────────────┐
  │  按键    │  功能                                        │
  ├──────────┼──────────────────────────────────────────────┤
  │  1       │  切换到圣诞树形态                             │
  │  2       │  切换到散开形态                               │
  │  3       │  打开第一张照片                               │
  │  5       │  切换到爱心形态                               │
  │  ←       │  上一张照片                                   │
  │  →       │  下一张照片                                   │
  │  P       │  进入雪花绘画模式                             │
  │  Esc     │  退出绘画模式 / 关闭照片                      │
  │  + / =   │  增大画笔（绘画模式中）                       │
  │  - / _   │  缩小画笔（绘画模式中）                       │
  └──────────┴──────────────────────────────────────────────┘


================================================================================
  七、星河场景
================================================================================

  星河场景包含两个子场景，可以来回切换。

  ── 7.1 星轨子场景（默认） ──

  画面中央有一个发光的原子核结构，周围环绕着多条粒子轨道环，
  配合字幕屏显示你的名字和祝福语。背景是深邃的星空。

  ── 7.2 爱心子场景 ──

  画面中央有双心粒子系统，配合剪影图片展示和祝福文字。

  ── 子场景切换 ──

  键盘快捷键：
  ┌──────────┬──────────────────────────────────────────────┐
  │  按键    │  效果                                        │
  ├──────────┼──────────────────────────────────────────────┤
  │  1       │  切换到星轨子场景                             │
  │  2       │  切换到爱心子场景                             │
  └──────────┴──────────────────────────────────────────────┘

  屏幕底部中央有场景指示器，显示当前所在的子场景：
    "1 · 星轨  |  2 · 爱心"
  当前激活的子场景名称会高亮显示为金色。

  ── 3D 视角控制 ──

  与圣诞场景相同：
  ┌─────────────────────────────────────────────────────────┐
  │  电脑：                                                  │
  │    鼠标左键拖拽 —— 旋转视角                              │
  │    鼠标右键拖拽 —— 平移视角                              │
  │    鼠标滚轮 —— 缩放                                     │
  │                                                         │
  │  手机：                                                  │
  │    单指拖拽 —— 旋转视角                                  │
  │    双指捏合 —— 缩放                                     │
  │    双指拖拽 —— 平移视角                                  │
  └─────────────────────────────────────────────────────────┘


================================================================================
  八、全局控制按钮
================================================================================

  以下按钮在多个场景中始终可用：

  ── 静音按钮 ──
  ┌─────────────────────────────────────────────────────────┐
  │  位置：屏幕右上角                                        │
  │  图标：🔊（有声）/ 🔇（静音）                            │
  │  点击切换静音/取消静音                                    │
  └─────────────────────────────────────────────────────────┘

  ── 返回按钮 ──
  ┌─────────────────────────────────────────────────────────┐
  │  位置：屏幕左上角                                        │
  │  图标：←                                                 │
  │  在欢迎场景及之后的场景中显示                             │
  │                                                         │
  │  点击效果：                                              │
  │    圣诞/星河场景 → 返回场景选择器                         │
  │    场景选择器 → 返回欢迎场景                              │
  │    欢迎场景 → 返回礼盒场景                               │
  └─────────────────────────────────────────────────────────┘

  注意：圣诞场景和星河场景各自还有一个独立的返回按钮
  （位于左上角，← 图标旁边），点击直接返回场景选择器。


================================================================================
  九、手机端特别说明
================================================================================

  1. 首次打开时，浏览器可能需要你点击一下屏幕才能播放音乐
     （这是浏览器的自动播放策略限制）。

  2. 雪花绘画模式在手机上使用手指滑动操作，体验与电脑端一致。

  3. 键盘快捷键（数字键 1/2/3/5、P 键等）仅在电脑端可用。
     手机端主要通过点击和手势操作。

  4. 3D 视角控制在手机上使用触摸手势：
     单指拖拽旋转，双指捏合缩放，双指拖拽平移。

  5. 如果画面卡顿，系统会自动检测设备性能并降低画质，
     无需手动调整。


================================================================================
  十、常见问题
================================================================================

  问：打开链接后一直显示"星河正在苏醒..."？
  答：请等待资源加载完成。如果长时间无反应，尝试刷新页面。

  问：礼盒点不动？
  答：需要准确点击到礼盒本体上，而不是背景区域。

  问：没有声音？
  答：检查右上角是否为静音状态（🔇），点击切换为 🔊。
      部分浏览器需要先与页面交互（点击任意位置）才能播放音频。

  问：画面很卡？
  答：系统会自动降低画质以适配设备性能。如果仍然卡顿，
      建议关闭其他占用 GPU 的程序，或使用性能更好的设备。

  问：如何重新体验？
  答：使用左上角的返回按钮逐步返回到礼盒场景，
      或直接刷新页面从头开始。

  问：可以自己上传音乐吗？
  答：可以。在圣诞场景中展开右下角的音乐播放器，
      点击底部的"Add Music"按钮选择本地音乐文件。
